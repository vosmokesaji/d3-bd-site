# i18n 文案来源报告

统计基于 2026-09-10 当前源码中的 13,123 条展示文案。这里的“官方”仅表示文字来自已提取的暴雪 PC 客户端资源；国服与国际服客户端版本不同，且 Switch 客户端尚未核验。

## 总体分类

| 分类 | 条数 | 占比 | 处理方式 |
| --- | ---: | ---: | --- |
| 完整采用官方客户端文本 | 2,581 | 19.7% | 原站完整文本与客户端精确匹配，或仅数字不同且公式、固定数字及其余文字完全一致。三语直接取客户端原文，原站数值保持不变。 |
| 仅由官方术语组成 | 2,790 | 21.3% | 整条文案只包含可追溯的装备、套装、技能、符文、属性或界面术语，按所选语言读取客户端原文。 |
| 官方术语与本站原创说明混合 | 3,094 | 23.6% | `[[Items/...]]`、`[[Powers/...]]` 等片段使用客户端原文，连接语、攻略判断和操作说明重新翻译。 |
| 本站原创文案 | 4,645 | 35.4% | 客户端没有对应原文。简中保留本站原意，繁中经转换并人工覆盖，英文经 googletrans 批处理并人工覆盖重点文案。 |
| 本站自定义术语 | 12 | 0.1% | “冲层、速刷、低巅峰”等攻略用语使用 `Site/...` 词条，明确不标为官方译文。 |
| 数量单位格式化 | 1 | <0.1% | 只转换原文明确写出的万、亿、码等单位，不计算游戏公式。 |

前两类共 5,371 条可以整体视为官方客户端 i18n。第三类只能把其中带来源标识的游戏元素视为官方文字，整句不能标为官方译文。后三类属于本站内容或格式规则。

## 官方客户端文本的组成

精选客户端术语共 3,579 条，只进入正式源码中本站实际使用的部分，没有把完整客户端语料打包进前端。

| 客户端文本表 | 条数 | 主要用途 |
| --- | ---: | --- |
| `Items` | 2,353 | 装备、传奇宝石及物品名称 |
| `AttributeDescriptions` | 815 | 符文、属性和描述片段 |
| `Powers` | 307 | 主动技能、被动技能和随从技能 |
| `ItemSets` | 69 | 套装名称及相关文字 |
| `SkillsUI` | 11 | 力量、智力、暴击几率等技能界面属性 |
| 其他 9 个表 | 24 | 职业、随从、卡奈魔盒、大秘境及少量通用界面文字 |

典型示例：

- `Items/P3_Unique_Ring_107` 对应皇家华戒、皇家華戒和 Ring of Royal Grandeur。
- `SkillsUI/ParagonBonusLabel_Crit_Percent_Bonus_Capped` 对应暴击几率相关显示。
- `AttributeDescriptions/NameRune_c#Necromancer_BoneArmor` 对应白骨脱臼的正确符文身份，不沿用旧页面中冲突的符文字母。
- 纸娃娃的 `+1000 智力`、`+10% 暴击几率`只保留本站数值，属性名读取客户端词条。

正式数据位于 `app/i18n/client-terms.json` 和 `app/i18n/client-texts.json`。来源版本、文本表名、原始键、匹配方式和候选记录分别保存在 `docs/i18n/client-evidence.json` 与 `docs/i18n/client-text-matches.json`。

## 重新翻译的内容

重新翻译范围包括网站导航、按钮、提示、攻略摘要、BD 选择理由、装备词缀建议、输出循环、作者分析、导出提示和错误信息。这些内容在客户端内没有可以安全认领的对应字符串。

- 英文先保护官方术语、数字、参数和稳定引用，再使用经授权的 googletrans 批处理；89 组重点词句在 `app/i18n/manual.json` 中人工覆盖。
- 繁中原创文案由简中转换生成，再对界面用语和攻略表达做人工覆盖。
- `app/i18n/site-terms.json` 单独保存本站攻略术语，避免它们与客户端译文混在一起。
- `googletrans` 是非官方 Python 客户端，并非 Google Cloud Translation 官方 SDK。它只负责本站原创内容，不能使机器译文变成官方游戏译文。

混合文案会保留边界。例如“魔女冷却最通用；冲层若需要暴击爆发可换盗贼”中的魔女、盗贼及具体技能名称来自客户端，策略判断和连接语属于本站翻译。

## 如何判断单条文案

1. 在 `scripts/i18n/message-definitions.json` 中按稳定 `app.<hash>` 键查找原文和模板。
2. 模板为 `[[Items/...]]`、`[[Powers/...]]`、`[[ItemSets/...]]`、`[[SkillsUI/...]]` 或 `[[AttributeDescriptions/...]]` 时，该片段来自官方客户端。
3. 整个 `app.<hash>` 同时存在于 `app/i18n/client-texts.json` 时，整条三语文本已通过完整客户端文本匹配。
4. 模板中的普通文字属于本站内容；`[[Site/...]]` 是本站术语；`[[Number/...]]` 是数量格式规则。
5. `docs/i18n/message-sources.json` 可继续追溯该文案出现在哪个组件或数据文件中。

## 尚未认领为官方的内容

- 两份中文客户端都缺少旧随从技能 `Powers/Scoundrel_Multishot_name`。
- 5 组旧攻略符文无法用现有身份和描述唯一确认。
- 80 个通用别名仍有跨条目或跨地区候选，71 条完整文本存在结果不同的候选。
- Switch 客户端文本、平台专用措辞和可能的效果差异均未核验。

这些内容保留明确待核对状态，不会静默借用另一中文地区译名。完整清单见 `docs/i18n/review-queue.json` 和 `docs/i18n/translation-failures.json`。
