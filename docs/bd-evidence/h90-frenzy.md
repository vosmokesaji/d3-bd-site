# 九十蛮狂乱证据档案

## 1. 身份与当前结论

- BD ID：`h90-frenzy`
- 赛季 / 补丁：第 39 赛季 / 2.7.8
- 当前证据状态：`source-checked`
- 当前平台状态：`platform-risk`
- 数据来源：人工逐字段录入，不再经过通用四象限工厂
- 校对日期：2026-09-14
- 当前可展示用途：单人 GR 冲层、GR 速刷、T16 小秘境、悬赏
- 暂不展示用途：敌意幻象；没有独立用途与配置证据

核心裁决：九十蛮不是只能冲层。Icy Veins 当前主导航只给它显示 `solo / gr-pushing / mid-tier`，但同一套指南在 S39 明确维护了独立 GR 速刷页和 T16 小秘境 / 悬赏页；d3guides 也提供冲层、速刷、T16 三个变体。因此不能仅凭导航标签删除速刷，也不能把四个真实用途误解为旧项目的“高低巅峰四格”。

另一个核心裁决：高巅峰不自动等于胸腿全白宝石。Icy 明确要求先用红宝石，只有坚韧不足已经阻碍推进时才换白宝石，并写明没有具体断点。高巅峰通常会带来更多力量和护甲，是否需要全抗取决于实际坚韧，而不是 `2000+` 标签。

## 4. 三套真实配置

### 4.1 单人 GR 冲层

- 穿戴：5 件九十蛮、奥吉德护肩 + 护腕、无可争辩的勇士、无尽之途、力量指环、伊斯特凡对剑。
- 技能：狂乱 `怒气冲天`、狂暴冲锋 `无情突袭`、战吼 `老兵之诫`、威吓呐喊 `惊魂余音`、战斗怒火 `血溅十方`、狂战之怒 `癫狂`。
- 被动：狂暴、狂战盛怒、布尔凯索的庇佑、无情暴虐。
- 魔方：兵要护符、深渊挖掘裤、皇家华戒、S39 第四槽守誓者。
- 传奇宝石：困者之灾、至简之力、受罚者之灾。
- 普通宝石：头部白、胸腿红、双武器绿。
- 随从：盗贼。

旧项目的 `狂人 / 顽抗战吼 / 恫吓` 不是 Icy 当前冲层表中的符文。它们分别被修正为 `怒气冲天 / 老兵之诫 / 惊魂余音`。这不是显示别名问题，而是会改变元素和防御 / 增伤行为的内容错误。

### 4.2 GR 速刷

- 保留 5 九十蛮 + 2 奥吉德骨架。
- 首饰改为斯奎特、力量指环、全能法戒。
- 武器改为寅剑 + 守誓者；第四槽改回荡狂怒。
- 冲锋默认寒冰冲撞；寅剑不稳定时应改回无情突袭。
- 第三颗传奇宝石改火牛羚砂囊，用护盾帮助保持斯奎特层数。
- 第四被动改好斗勇者；随从改魔女。
- 玩法仍是精英追杀，必须跳过零散怪；不能把它当范围清图 BD。

Icy 同一 GR 速刷页存在一处内部冲突：顶部技能速查表显示战吼 `老兵之诫`，逐条适配正文写 `赦免`。当前配置采用更具体的正文 `赦免`，结论保持 `single-source` 并记录冲突，不能标为交叉完成。

### 4.3 T16 / 悬赏

- 脱奥吉德护肩，穿九十蛮护肩；脱九十蛮裤，穿深渊挖掘裤。皇家华戒继续补足六件。
- 穿沃兹克护腕、瑞秋的行窃之戒、力量指环、寅剑 + 守誓者。
- 技能改狂乱 `无情先锋`、冲锋 `无情突袭`、战吼 `老兵之诫`、疾奔 `奔跑健将`、战斗怒火 `凶残`、狂战 `癫狂`。
- 被动改狂战盛怒、狂暴、布尔凯索、血肉铸就。
- 魔方为兵要护符、金织带、皇家华戒、回荡狂怒；明显碾压内容后可用齐拉尼克替代金织带。
- 传奇宝石为囤宝者、至简、困者；随从魔女携带贪婪之戒和复仇者护腕。
- 瑞秋只由恐惧触发，冰冻和眩晕不能替代；武器需要可靠的恐惧命中副词缀。

Icy 单人推荐带合适被动的地狱火项链，组队推荐时光流韵。当前本地资源库只有地狱火图纸图，没有准确成品图；页面暂时显示同一来源明确支持的时光流韵，并在选择策略中写明单人最优差异。这是展示资产阻塞，不能偷偷把组队替代写成单人最优。

## 5. 普通宝石与巅峰裁决

### 5.1 为什么不是“高巅峰直接全白”

Icy 的原始顺序是：

1. 胸甲和裤子先装最高等级红宝石。
2. 随着巅峰力量提高、目标 GR 变危险，再考虑白宝石。
3. 没有具体断点；只有“坚韧不足阻碍推进”才是切换条件。

因此页面默认配置保留 5 颗红宝石，并把白宝石写成条件替换。验证方法不是看巅峰数字，而是：力量指环是否有空窗、狂乱是否保持 10 层、在两条防线都正确时是否仍被常见伤害击杀。只有最后一种情况才应优先换白。

### 5.2 800 点前巅峰

- 核心：移速至装备 + 巅峰合计 25%，力量，体能按需，最大怒气跳过。
- 进攻：冷却缩减、暴击几率、暴击伤害、攻击速度。
- 防御：全元素抗性、生命%、护甲、生命恢复。
- 功能：击中回复生命、范围伤害、拾取范围、能量消耗降低。

800 点后继续按力量 / 体能和装备功能词缀的实战瓶颈调整。手套力量让给范围伤属于装备质量与成长条件，不是所有 `2000+` 角色的自动动作。

## 6. 来源冲突与裁决

| 冲突 | Icy Veins | d3guides | 当前裁决 |
| --- | --- | --- | --- |
| 主导航用途 | 只显示冲层标签 | 显示冲层、速刷、T16 | 具体 Icy 子页也支持速度用途，以精确子页为准 |
| S39 冲层穿戴槽 | 奥吉德肩 + 胸甲九十蛮 | 九十蛮肩 + 奥吉德胸 | 不混拼；当前选择 Icy S39 完整方案 |
| S39 冲层武器 / 第四槽 | 伊斯特凡对剑 / 守誓者 | 碧蓝怒火 + 守誓者 / 全能 | 不把不同完整方案拆开组合 |
| 冲层技能符文 | 怒气冲天、无情突袭、老兵之诫、惊魂余音、血溅十方、癫狂 | 四个主动符文不同 | 当前采用 Icy 完整技能栏；四被动双源一致 |
| 普通宝石 | 红起步，坚韧不足时换白，无固定断点 | 直接护甲白，且写“其余 8 孔” | 拒绝自动高巅峰全白；数量异常降低第二来源权重 |
| GR 速刷战吼 | 同页速查表老兵之诫、正文赦免 | 不足以关闭冲突 | 暂按更具体正文用赦免，并保持未交叉状态 |

d3guides 可以证明“这个用途存在”，也能交叉确认机制、前三魔方槽、冲层宝石和四被动，但它不能因为更新时间更晚就自动覆盖另一套完整方案。准确性要求先检查字段能否组成闭环，而不是多数表决或整页照抄。

## 7. 自动验证

当前代码必须通过以下检查：

1. `validateReviewedBuildGuide()`：四个场景可解析；悬赏通过 `sameAsScenarioId` 真实复用 T16；不存在未知装备、技能、被动或威能。
2. `validateBuildSemantics()`：三个配置无重复穿戴、非法双手 + 副手或通用高巅峰钻石模板。
3. `validateBuildEvidence()`：12 个结构化来源均为精确 HTTPS 页面；场景用途与来源 `content` 一致；20 条结论引用已登记来源。
4. 数据回归：场景严格为 `gr-push / gr-speed / t16-rift / bounty`，不存在 `push-low / push-high / speed-low / speed-high`。
5. 数据回归：基础为 5 红、双武器绿；白宝石只作为带条件和代价的替换。
6. 数据回归：GR 速刷必须换首饰与武器包；T16 必须同时换肩、裤、护腕、首饰、技能、被动、魔方和宝石。
7. 页面回归：四个用途、火牛羚、寅剑、斯奎特和“无固定巅峰断点”可见；旧高低巅峰按钮不可见。
8. i18n：简中、繁中和英文均不能出现待翻译占位或原始客户端引用。

## 8. Nintendo Switch 最小实测清单

当前环境不能替代设备侧验证，以下全部完成前不得升级到 `switch-tested`：

### 冲层样本

1. 记录角色面板、目标 GR、巅峰、宝石等级和装备词缀。
2. 用手柄连续锁定同一精英，确认狂乱能稳定到 10 层且不会因目标吸附频繁断层。
3. 连续三次记录狂暴冲锋后力量指环减伤是否刷新、冲锋落点是否可控。
4. 分别在红宝石和白宝石下完成同一目标层至少三次，记录死亡原因、完成时间与首领耗时；不能只看面板坚韧。

### GR 速刷样本

1. 在寅剑未启动时验证无情突袭启动路线；启动后验证寒冰冲撞不会造成冲锋断档。
2. 连续三局记录首组精英击杀时间、寅剑 / 回荡狂怒覆盖和斯奎特层数。
3. 验证火牛羚护盾在主机受击与延迟条件下能否稳定保护斯奎特；失败时记录强者之灾 / 无尽之途替代。

### T16 / 悬赏样本

1. 确认武器恐惧命中能触发瑞秋，单独的眩晕或冰冻不能误判为触发。
2. 确认随从贪婪之戒、复仇者护腕的发散行为和金织带金币护甲。
3. T16 小秘境与至少一个长距离悬赏各跑三次，记录寅剑断档、空图疾奔和拾取体验。
4. 分别测试时光流韵和正确被动的地狱火项链；补齐地狱火成品图后再决定页面默认。

每个样本保存截图或视频路径、角色条件、结果和失败原因。只有关键触发全部可复现、来源冲突关闭、页面和移动端验收完成后，才允许从 `source-checked / platform-risk` 升级。
