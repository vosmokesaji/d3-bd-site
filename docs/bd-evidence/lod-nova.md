# 梦遗死亡新星证据档案

- Build ID：`lod-nova`
- 基线：S39 / 2.7.8 / Nintendo Switch / Solo
- 当前证据状态：`source-checked`
- 当前平台状态：`platform-risk`
- 数据来源：人工逐字段校对
- 发布状态：不可发布；Icy 页内旧文、第二来源完整配装冲突、Maxroll 正文缺失和 Switch 实测尚未关闭

## 1. 本轮结论

旧版把梦遗新星强行拆成“低/高巅峰冲层”和“低/高巅峰 T16”四格，并为 T16 批量拼入寅剑、复仇者、斯图亚特、金织带、贪婪之戒和囤宝者。当前可读来源不能证明这套物理配置应当这样切换，因此四格全部删除。

现在只开放两个用途：

1. `gr-progression`：Icy 的物理鲜血新星单人 GR 推进配置，适用性为 `viable`。
2. `gr-speed`：低层 GR 保守速刷，只采用 Icy 明确写出的“受罚者换强者”，适用性为 `viable`。

不开放 T16、敌意幻象、悬赏、梦魇回响或外观农场。第二来源确实提供 T16 变体，但它属于毒新星、团结、斯图亚特和另一组技能/魔方组成的完整方案；把其中几件单独塞回 Icy 物理方案会变成未经来源验证的混拼。

## 4. 来源冲突与裁决

### 4.1 Icy 自身的页内旧文

Icy 当前技能表是鲜血虹吸、死亡新星、血魂双分、鲜血穿行、骨甲和脆弱；同一技能页正文却残留“亡者领域·寒冰大地驱动克里斯宾”的旧说明。装备页也重复了亡者领域的解释。

裁决：技能栏、Quick Reference 和当前 S39 第四槽说明彼此相符，采用骨甲与轮回镰刀；旧亡者领域段落登记为未解决冲突，不用于生成配置。这也是整套仍只能标记 `source-checked` 的原因之一。

### 4.2 Icy 物理方案与 d3guides 毒方案

两站一致：葬镰、铁玫瑰、鬼灵面容、梦之遗礼、血潮利刃、戴恩提、轮回镰刀，以及推进三宝石困者/受罚者/梦遗。

两站不一致：

- Icy 使用物理鲜血新星、力量转移、鲜血灌注、白骨脱臼、脆弱光环；d3guides 使用毒新星和另一组符文。
- Icy 使用克雷姆护腕、攀冰者、全能法戒和卡兰之睿；d3guides 使用古帕萨、斯图亚特、团结，并把全能法戒放入魔方。
- Icy 的头部宝石是白宝石；d3guides 表格是紫宝石，但同页结尾又称“其余七孔全黄”，自身也不一致。
- d3guides 提供独立 speed/T16 变体，但它们建立在其毒新星基础配置上，不能只抽取斯图亚特、金织带等少数条目拼入物理方案。

裁决：当前 UI 保留 Icy 完整物理方案，第二来源只提高共同发动机、梦遗纪律、推进宝石和用途存在性的证据等级。所有完整配装差异保持 `unverified`。

## 6. 当前完整配置

### 6.1 单人 GR 推进

- 装备：李奥瑞克王冠、导能披肩、天鹰胸甲、岩石护手、克雷姆护腕、巫异时刻、单件黑荆棘裤、攀冰者、鬼灵面容、克里斯宾、全能法戒、葬镰、铁玫瑰。
- 技能：力量转移、鲜血新星、鲜血与白骨、鲜血灌注、白骨脱臼、脆弱光环。
- 被动：迅捷收割、无尽折磨、咒怨之力、孤魂死灵。
- 魔方：血潮利刃、戴恩提、卡兰之睿、第39赛季轮回镰刀。
- 传奇宝石：困者、梦遗、受罚者。
- 普通宝石：头部白、胸裤黄、武器绿。
- 随从：盗贼；Icy 只明确到随从选择，具体装备/技能仍需逐项核对。

### 6.2 低层 GR 速刷

与推进配置相同，只把受罚者换成强者。触发条件不是“高巅峰”，而是目标低层的精英可以连续击杀，守关者不再需要长时间叠受罚。若首领明显拖时，应切回受罚者或降低层数。

## 7. 成长条件：如何查、如何验证

### 7.1 不再用 2000 巅峰作为硬线

每次只改变一个变量并保存三场样本：

1. 记录巅峰、梦遗等级、远古件数、卡德山、面板生命、冷却和攻击速度。
2. 选择同一目标层和尽量相近的地图条件，连续跑三场。
3. 记录总用时、死亡、精英平均耗时、守关者耗时、断骨甲/断天鹰/无诅咒死亡次数。
4. 只有三场都显示同一瓶颈时才换词缀、宝石或装备；一次只换一项，再跑三场对照。

判定示例：

- 生存不够：常见地板或精英词缀导致无法完成一个物理周期，先补体能/生命/护甲或恢复运行条件。
- 单体不够：守关者占总时间过高，保留受罚者，不要为了“速刷标签”强换强者。
- 密度收益不够：经常对少量怪原地虹吸，先改善聚怪和路线，不要直接把问题归咎于巅峰。
- 远古升级：只有同名远古保留关键威能和词缀时才替换；错误远古不能因为边框颜色而胜过正确普通传奇。

### 7.2 T16 重新开放条件

满足以下任一证据路径后，才能重新建立 T16 场景：

- 人工读取 Maxroll 当前精确指南，确认其 T16/NR Planner 与版本，并逐项保存完整配置；或
- 找到另一份当前 S39、能显示装备/技能/被动/四魔方槽/宝石的独立精确来源；或
- 在 Switch 上分别完整实装 Icy 物理候选与 d3guides 毒候选，各跑三次 T16，并记录完整装配和结果。

不可接受的验证：只证明“这套能过 T16”、只看到某件装备出现在搜索摘要、或把其他死亡新星 BD 的金币链复制过来。

## 8. Nintendo Switch 最小实测单

对 `gr-progression` 与 `gr-speed` 分别记录：

- 完整装备、技能、符文、被动、四魔方槽、三颗传奇宝石和随从截图。
- 鲜血虹吸自动锁定是否能稳定选择精英，右摇杆/站位如何改变方向。
- 鲜血灌注的落点、穿怪、回血是否符合页面说明。
- 手动死亡新星与持续虹吸能否在手柄布局中同时顺畅执行。
- 双分是否持续复制新星；死亡、换层、回城后何时需要重开。
- 骨甲层数、轮回镰刀、戴恩提、天鹰和克里斯宾的可观察覆盖。
- 每个场景连续三场：层数、用时、死亡、守关者耗时和异常。

完成上述功能验证只能提升到 `switch-tested`；要成为 `published`，还需解决完整配置冲突、UI 验收和来源覆盖。
