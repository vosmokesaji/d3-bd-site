# 项目最终目标与差距记录

更新日期：2026-08-31

## 最终目标

圣休亚瑞秘典的核心不是配装清单，而是让玩家围绕 BD 装备纸娃娃、技能配置、卡奈魔方萃取、巅峰加点和物品关联，快速看懂一套 BD 为什么这样构筑、每个模块怎样互相支撑，以及在不同赛季主题中应如何切换。

最终体验应满足：

1. PC 端进入 BD 详情后，首屏尽可能同时看到纸娃娃装备、技能、萃取、巅峰/场景选择和核心构筑原因；避免为了理解一套 BD 在三四屏之间来回跳。
2. 手机端能完整查看 BD、物品和关联信息，优先保证阅读顺序、横向滚动边界和触控可用性。
3. 能方便切换赛季；短期只需支持未来少数几个轮换赛季主题，不追求无限历史赛季。
4. 装备和 BD 双向关联：BD 中能打开装备详情，装备详情能看到哪些 BD 使用它，并说明该装备在对应 BD 中承担的作用。
5. UI 美观、接近暗黑破坏神 III 游戏 UI；视觉参考暴雪网站与游戏内装备框、纸娃娃、技能和魔方质感。
6. 项目结构符合编程规范：数据、组件、样式、测试和文档边界清晰，后续逐套补 BD 不需要反复改页面大文件。

## 当前状态

已完成或基本达标：

- 全职业 BD 列表、BD 详情、物品目录、物品详情和本地物品镜像已可用。
- BD 详情已有纸娃娃、技能、魔方、巅峰、场景切换、联动图、随从和手法模块。
- 已建立 `configurationBase + scenarios` 的数据契约，完整 BD 可以由真实配置驱动。
- BD 装备可以打开物品详情，物品详情可以反查相关 BD。
- 装备框、随从纸娃娃、字号 token、主要回归测试已建立。
- 手机端已有基本降级布局。

核心差距：

1. PC 首屏两列重构已完成：纸娃娃完整可见，文字与交互层不再整体缩放；右侧以“构筑总览 / 装备作用”分层承载首屏决策信息。后续只做真实数据补充和分辨率微调，不再回到三列压缩方案。
2. 已建立可切换的赛季主题层：当前赛季及三槽、四槽两种轮换预设可在页头和网站设置中切换；未来真实赛季仍需补入经过校对的具体 BD 配置，而不是把预设当成实装数据。
3. 51 套 BD 仍未全部逐套校对。未校对 BD 会保留说明型数据，不能代表真实场景差异。
4. BD 详情仍集中在 `app/page.tsx` 和单一大样式文件中，组件边界不够利于长期维护。
5. UI 已接近游戏质感；PC 首屏已转为“游戏面板式指挥台”，后续重点是各分辨率下的可读性和模块高度微调。
6. 手机端可看，但还需要针对 BD 首屏、装备详情、关联 BD 和纸娃娃横向滚动做专项验收。

## 近期执行方向

按优先级推进：

1. 为未来真实赛季补入经校对的 BD 配置覆盖层，并在主题切换时优先读取对应配置。
2. 继续逐套校对剩余 BD，每套只在数据层表达真实配置差异。
3. 拆分 BD 详情运行时和样式，降低 `app/page.tsx` 与 `app/globals.css` 的维护压力。
4. 对桌面和手机做持续视觉回归，重点检查首屏密度、文字可读性和暗黑风格一致性。
