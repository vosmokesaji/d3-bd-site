# 圣休亚瑞秘典：项目文档

本文档对应“圣休亚瑞秘典”暗黑破坏神 III 单人攻略站。项目以 Nintendo Switch、简体中文界面、第 39 赛季为当前内容基准，重点不是简单罗列配装，而是把装备、技能、符文、被动、卡奈魔方和套装效果之间的因果关系图形化。

## 当前功能范围

| 功能 | 路由 | 当前实现 |
| --- | --- | --- |
| 全职业 BD 列表 | `/builds` | 7 个职业、51 套单人 BD |
| BD 详情 | `/builds/:id` | 统一数据驱动渲染器；配置切换已接入，51 套真实差异正逐套校对 |
| 赛季开荒 | `/season-start` | 0–70 级、首套成型和职业推荐 |
| 剧情线路 | `/story` | 五幕主线、任务节点、区域和通关目标 |
| 物品目录 | `/library` | 55 个官方分类，支持职业、随从和工匠筛选 |
| 物品列表 | `/library/:category` | 品质筛选、名称搜索、等级排序 |
| 物品详情 | `/library/:category/:id` | 结构化属性、套装清单、套装档位和本地图标 |
| 网站设置 | 全站顶部入口 | 可按职业选择纸娃娃性别，也可一键全部切换 |

## 数据规模

- 51 套 BD：野蛮人 7、圣教军 9、猎魔人 6、武僧 8、死灵法师 7、巫医 7、魔法师 7。
- 2353 条物品记录，全部使用 `schemaVersion: 2`。
- 55 个物品分类：24 个防具/副手分类、23 个武器分类、8 个其他分类。
- 337 条套装品质记录，其中 319 件实际装备包含结构化套装部件和档位；另外 18 条是套装设计图。
- 294 个技能图标、177 条宝石数据、14 张职业男女纸娃娃背景。
- `public/d3` 静态资料约 32 MB，物品图标约 21 MB。

## 技术概览

- React 19 + Next.js App Router API。
- vinext + Vite，将应用编译为 Cloudflare Worker 兼容产物。
- TypeScript 编写页面、构筑数据与构建逻辑。
- 物品库使用静态 JSON 和本地图标，不依赖运行时数据库。
- Node.js 脚本负责抓取、缓存、解析和生成暴雪官网物品资料。
- Node Test Runner 对路由、51 套 BD、纸娃娃几何和物品结构进行回归验证。
- 项目预留 Drizzle/D1 接口，但当前 `.openai/hosting.json` 中 D1、R2 均未启用。

## 快速开始

环境要求：Node.js `>= 22.13.0`。

```bash
npm install
npm run dev -- --port 3001
```

打开 `http://localhost:3001/`。完整验证使用：

```bash
npm test
```

## 当前边界

- 首版只覆盖单人玩法，不包含组队辅助 BD。
- 内容以 NS 使用体验为主要校对对象，但绝大多数数值与机制沿用 PC 版资料。
- 第 39 赛季、补丁标识和部分说明目前写在数据或页面代码中，赛季切换还没有独立配置中心。
- 网站设置使用浏览器 `localStorage`，不会跨设备同步。
- 当前没有用户账号、收藏、云端保存或写入型业务数据。
